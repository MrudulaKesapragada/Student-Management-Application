This project is the first phase of a full-stack Student Management Application. This initial version is a fully client-side application built with HTML, CSS, and  JavaScript, focusing on a modern, responsive, and feature-rich user interface. and for the back end node js.

🚀 Features

Four Main Sections:

Student: A comprehensive list of all enrolled students with key details.

Attendance: An interface to easily mark daily student attendance.

Performance: Visual insights into student grades, including a detailed table, a bar chart for grade distribution, and a "Top Performers" leaderboard.

Dashboard: A high-level overview of key metrics, including total students, attendance rate, and class average grade, displayed with interactive donut charts.

Full CRUD Functionality:

Create: Enroll new students via a simple and intuitive form.

Read: View and sort the list of all students.

Update: Edit the details of any existing student through a pop-up modal.

Delete: Remove students with a safe confirmation step.

Modern User Experience (UX):

Interactive Charts: Data visualization powered by Chart.js.

Toast Notifications: Non-intrusive feedback for actions like adding or deleting students.

Modals: Clean and focused pop-ups for editing and confirmation.

Skeleton Loading: An elegant loading animation that simulates fetching data.

Responsive Design: The layout is fully responsive and works beautifully on desktops, tablets, and mobile devices.

🛠️ Technology Stack

HTML: The core structure of the application.

CSS: A utility-first CSS framework for rapid and modern UI development.

JavaScript (ES6+): Handles all the application logic, state management, and DOM manipulation.

Chart.js: A powerful library for creating beautiful and interactive charts.

Node js: For handling the backend.

Font Awesome: Used for icons throughout the application.

 How to Run the Application

This is a single-file application, so running it is very simple. The recommended method is using the Live Server extension in Visual Studio Code.

Save the File: Make sure you have the code saved as student-management-frontend.html.

Install Live Server in VS Code:

Open VS Code and go to the Extensions view (Ctrl+Shift+X).

Search for "Live Server" by Ritwick Dey and click Install.

Run the File:

Open student-management-frontend.html in VS Code.

Right-click anywhere in the editor and select "Open with Live Server".

Alternatively, click the "Go Live" button in the bottom-right corner of the VS Code window.

Your default browser will open the application. Any changes you save to the file will now automatically reload in the browser.
